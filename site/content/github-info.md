## Recent updates
- **ReviewBench: An open benchmark for AI code review**: GitHub launched ReviewBench, a benchmark for code review agents using real pull requests and production-aligned metrics ([GitHub Blog](https://github.blog/ai-and-ml/github-copilot/reviewbench-an-open-benchmark-for-ai-code-review/)).
- **Claude Haiku 5.5 in GitHub Copilot**: Claude Haiku 5.5 is now available in GitHub Copilot, enhancing AI-powered code suggestions ([GitHub Changelog](https://github.blog/changelog/2026-10-07-claude-haiku-5-5-in-github-copilot)).
- **Triage role users can now archive pull requests**: Users with the triage role or higher can archive pull requests for better repository management ([GitHub Changelog](https://github.blog/changelog/2026-10-08-triage-role-users-or-higher-can-now-archive-pull-requests)).
- **OSPO Org Health Workflow**: The OSPO Org Health workflow provides weekly health reports for organizations, surfacing stale issues/PRs and contributor leaderboards ([Awesome Copilot](https://github.com/github/awesome-copilot/blob/main/workflows/ospo-org-health.md)).
